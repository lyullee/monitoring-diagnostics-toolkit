# 공개된 실제 설비·실험 데이터 평가 — 0.4.0

공개 원시 데이터를 내려받아 현재 진단기에 실제 입력했습니다. 적용한 것은
**밸브 추종 오차와 냉동기 열성능 2종**이며, 나머지 8종은 필수 센서·독립 고장 정답·
공개 접근성·현재 물리 모델의 범위가 맞지 않아 성능 수치를 산출하지 않았습니다.
다른 논문의 정확도를 이번 구현의 성능으로 가져오지 않았습니다.

## 실제 실행 결과

아래 정확도·검출률·오경보율은 **판단 가능한 표본**에 대한 이진 정상/이상 판정입니다.
고장 종류를 분류하는 정확도가 아닙니다. '고정 설정'은 평가 전에 정한 시험 설정이며,
라이브러리의 모든 기본 인수와 같다는 뜻이 아닙니다. 밸브 오차 4%·지연 0 s·지속 3 s,
냉동기 COP 저하 20%·접근온도 증가 3 K·지속 30 s를 고정했습니다.

| 모듈·설정 | 정확도 | 고장 표본 검출률 | 정상 표본 오경보율 | 평가 대상 중 판단률 |
|---|---:|---:|---:|---:|
| 밸브, 고정 설정 | 95.74% | 91.44% | 4.2560% | 100.00% |
| 밸브, 정상 자료로 보정 | 99.97% | 91.16% | 0.0221% | 99.998% |
| 냉동기, 고정 설정 | 49.22% | 32.67% | 23.0650% | 90.99% |
| 냉동기, 정상 자료로 보정 | 39.40% | 3.61% | 0.6583% | 90.99% |

정상 데이터가 매우 많은 밸브의 정확도는 단독으로 해석하면 안 됩니다. 보정 후
balanced accuracy는 95.57%, precision은 73.62%였습니다. 문서에 기록된
**공급압력 저하 f16 6건 중 6건**을 검출했고, 최초 경보 지연은 7–11 s였습니다.
고장 구간 전체를 검출로 간주하지 않아 고장 표본 검출률은 100%가 아닌 91.16%입니다.

냉동기는 오경보를 낮추면 검출률이 크게 감소했습니다. 현재의 단일 중앙값 COP 기준과
고정 접근온도 규칙만으로 이 실험의 다양한 부하·고장을 충분히 판별하지 못합니다.
정상 보정만으로 현장 적용 수준의 진단기가 되었다고 결론낼 수 없습니다.

## 지표의 분모와 판단 보류

```text
정확도 = (TP + TN) / (TP + TN + FP + FN)
검출률 = TP / (TP + FN)
오경보율(FPR) = FP / (FP + TN)
정밀도(precision) = TP / (TP + FP)
대상 중 판단률 = 판단 가능한 표본 / 평가 대상 표본
전체 대상 고장 검출률 = TP / (판단 보류를 포함한 평가 대상 고장 표본)
```

UNKNOWN을 정상 정답이나 TN으로 넣지 않았습니다. 오경보율은 정상 표본 중 오경보
비율이며 전체 경보 중 오경보 비율(1−precision)과는 다릅니다. 이 둘을 바꾸어 표기하지
않았습니다. 분모가 0인 지표는 null/산출 불가입니다.

| 보정 후 혼동행렬·판단 범위 | 밸브 | 냉동기 |
|---|---:|---:|
| TP | 639 | 2,573 |
| FN | 62 | 68,667 |
| FP | 229 | 280 |
| TN | 1,034,747 | 42,252 |
| 원본 평가 행 수 | 1,036,800 | 181,700 |
| 평가 대상 행 수 | 1,035,695 | 125,043 |
| 평가 대상 중 UNKNOWN | 18 | 11,271 |
| 원본 전체 대비 판단 비율 | 99.89% | 62.62% |

냉동기는 원본 평가 행의 31.18%를 사전에 정한 안정 운전 조건에 맞지 않아 평가 대상에서
제외했습니다. 따라서 대상 중 판단률 90.99%를 원본 전체 판단률로 읽으면 안 됩니다.
평가 대상 고장 표본의 판단률은 86.48%이고, UNKNOWN을 포함한 전체 대상 고장 검출률은
고정 설정 28.25%, 보정 후 3.12%입니다.
특히 증발기 유량 감소 20/30/40% 파일은 정상 학습 유량 범위 밖이어서 전부 UNKNOWN입니다.
이를 검출 성공이나 정상 판정으로 집계하지 않았습니다.

## 데이터와 분리 방법

### 밸브: 실제 공장 데이터

출처는 바르샤바 공과대학의 [DAMADICS 공식 페이지](https://iair.mchtr.pw.edu.pl/Damadics)와
해당 페이지의 공식 원시 데이터·설명서입니다. Lublin 제당 공장의 A1(주스 유입)과
A3(보일러 급수) 밸브를 사용했습니다. 설명서 Table 1의 명령·실측 위치 컬럼과
Tables 3/5의 고장 주입 시각을 대조했습니다.

- A1은 원본 6/7열, A3은 28/29열입니다. 둘 다 **닫힘 백분율**이므로 동일하게 100으로
  나눴습니다. 한 신호만 1−x로 뒤집지 않았습니다.
- 시간은 원본 1열의 자정 이후 초입니다. 자료는 1 Hz이며 날짜별로 별도 실행해
  계산 이력을 자정 너머로 연결하지 않았습니다.
- 지연 선택: 2001-10-29 자료에서 0–5 s 후보의 평균 절대 추종 오차를 비교했습니다.
- 임계값 보정: 별도 날짜인 2001-11-01의 정상 배경 자료에서 절대 오차 99백분위수를
  사용했습니다. A1은 지연 2 s·허용 오차 2.5%, A3은 지연 1 s·허용 오차 8.6%였습니다.
- 평가: 11월 8/9/17/20/21/22일의 6일×2개 밸브를 전부 처리했습니다.
- 주 평가 목표는 f16 공급압력 저하입니다. 다른 고장 f17/f18/f19의 알려진 구간은
  주 평가의 정상 구간에서 제외했고 별도 이벤트 결과로 남겼습니다. 이 구간을 정상으로
  몰래 취급하거나, 추종 오차로 모든 밸브 고장을 검증했다고 주장하지 않았습니다.
- 고장 시각은 문서의 시작~종료 초를 양끝 포함하여 사용했습니다. 주입 경계의 불확도와
  복구 응답의 영향이 남습니다. 이벤트 후 추가 유예 구간으로 오경보를 지우지 않았습니다.

**정상 배경의 한계:** 정상이라고 부른 것은 문서에 인위적 주입 고장이 없는 구간입니다.
정비로 독립 확인된 정상 구간은 아니며, 자연 고장·기록되지 않은 이상이 섞일 수 있습니다.
따라서 오경보율은 이 배경 라벨 기준입니다. 밸브 2개·고장 이벤트 6건의 결과를 다른 공장과
모든 고장 종류의 성능으로 일반화하지 않습니다.

### 냉동기: 실제 실험 설비 데이터의 공개 재배포본

출처는 Zengrui Tian의 [Figshare 공개 배포본](https://doi.org/10.6084/m9.figshare.28435232)입니다.
게시자는 ASHRAE RP-1043 자료이며 CC0라고 표시했습니다. 실제 수집 기관이 배포한
원본 서버에서 직접 받은 것은 아니므로 **공개 재배포본**임을 명시합니다. 원본 실험과
독립적인 진위 인증을 수행한 것은 아닙니다. 압축파일의 게시 MD5 및 자체 SHA256을 확인합니다.

- 'Complete Data Set' 시트의 원시 시계열을 사용했습니다. 'Steady States' 평균값을
  독립 시계열로 위장하거나 가상의 시각을 만들지 않았습니다.
- 정상 학습은 `normal.xls`, 보정은 `normal1.xls`, 평가는 다른 정상 운전 파일 12개와
  고장 파일 23개입니다. 학습·보정·평가 사이에 행을 섞지 않았습니다.
- 고장에는 증발기 유량 감소, 냉매 부족, 냉매 과충전, 응축기 오염, 과다 오일,
  비응축가스의 6종을 포함했습니다. 파일명과 원본 `read me first.xls`의 실험 설명으로
  라벨을 정했습니다. 자료의 `Active Fault`, 보고된 `COP`는 모델 입력에 넣지 않았습니다.
- 입력은 TEI/TEO/TCO, FWE, kW, PRE/PRC입니다. 화씨→K, US GPM→m3/s→kg/s,
  kW→W로 변환했습니다. 물 밀도 998.2 kg/m3·cp 4180 J/(kg·K)를 가정했습니다.
- 포화온도는 PRE/PRC의 psig에 대기압 101325 Pa를 더한 절대압으로 CoolProp R134a
  Q=1에서 계산했습니다. 순수 냉매·압력 기준에 대한 가정이며 비응축가스 고장에서는
  이 관계 자체가 부정확할 수 있어 해당 고장 결과를 따로 제공합니다.
- 안정 구간은 과거 300 s의 양측 물 입출구 온도 범위가 모두 1 K 이하이며, 최소 25개
  관측값·전력 >1 kW·유량 >1 GPM·냉수 입구>출구인 구간으로 사전 정의했습니다.
  미래 관측값으로 안정 여부를 판단하지 않았습니다.
- 일부 파일의 중복 시각은 같은 시각 첫 행을 유지하고 제거했습니다. 학습·보정·평가
  전체를 합해 135행이며 파일별 원본 행 수·제거 수는 data_audit에 기록했습니다.
  역행 시간은 임의 정렬로 숨기지 않고 오류로 중단합니다.
- 보정은 정상 보정 파일의 유효 원시 점수 99백분위수로 공통 점수 문턱값을 정했습니다.
  결과 문턱값은 약 1.79507입니다. 원래 점수 문턱값 1의 결과도 같이 제시했습니다.
  별도 보정 정책이며 핵심 진단기의 계산식·고장 분류 모델을 바꾼 것이 아닙니다.

단위는 [냉동기 변수 정의 자료](https://dr.ntu.edu.sg/server/api/core/bitstreams/f0ca8e15-d0f0-48ac-86dc-c13e4e8bf9e2/content),
실험·정상/고장 구분은 원본 배포본의 실험 설명으로 확인했습니다.
35개 평가 파일은 한 대의 냉동기에 대한 반복 실험입니다. 181,700행을 서로 독립인
181,700번의 실험으로 해석하지 않습니다. 독립 표본을 가정한 좁은 신뢰구간은 제시하지 않았습니다.

결론이 아니며, 필수 센서와 고장 정답이 있는 자료를 확보하면 추가 평가할 수 있습니다.
외부 연구에서 보고한 성능 수치를 빈칸에 채우지 않았습니다.

## 재현·검증·산출물

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[dev,physics,public-data]"
# 첫 실행: 원본 압축파일 다운로드. 이후 같은 명령은 캐시를 재사용
.\.venv\Scripts\python.exe scripts/validate_public_data.py --download
# 저장된 표본별 결과를 별도 CSV 재집계로 대조

```

프로토콜은 `outputs/public_validation/protocol.json`, 종합 결과는 `results.json`,
비교표는 `report.html`입니다. `chiller_results.json`과 `valve_results.json`에는 파일·
