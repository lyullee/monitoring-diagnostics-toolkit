# 구현 목록과 조사 항목의 상태

v0.12.0: 정상 학습·별도 보정으로 EWMA/CUSUM을 계산하는
`TemporalEvidenceDiagnostic` API와 필터의 트리 예측 차이·학습 범위 출력을 추가했다.
기존 감시와 결합한 히트펌프 개선은 재사용 평가다. 필터의 새 성능 후보는 미채택했다.
[1~6단계 결과·새 실측 자료에서 확인한 범위](DIAGNOSTIC_FOLLOWUP.md)를 확인하세요.

v0.11.0: `FilterRiskClassifier`는 분진 공급 조건·재료 종류를 추가 입력으로 사용하는
선택적 지도학습 API다. 히트펌프에는 기존 감시를 유지한 부하별 증발기 관련 감시를
추가했다. [재사용 평가·개발 후보·새 자료 미검증](FILTER_HEATPUMP_OPERATING_POINTS.md)을 확인하세요.

v0.10.0: 히트펌프에 확장 잔차·채널별 정상 보정을 추가했다. 별도 지도학습 API
`FilterServiceRiskModel`은 미래 600Pa 교체 한계까지 수명을 예측한다.
정상 기준 학습 CLI 11종과 구분한다.
[재사용 평가·이전 미사용 관측·독립 새 자료 미검증](FILTER_HEATPUMP_IMPROVEMENT.md)을 확인하세요.

v0.9.0: 필터 무차원 유량비 입력과 냉매측 난방 히트펌프 모듈을 추가했다.
[추가 실험 자료의 분리 검증·성능·한계](ACQUIRED_MODULES_VALIDATION.md)를 확인하세요.

최신 선택 기능(v0.8.0): 열교환기 유량별 열저항, RO 압력·온도 보정 입력,
기화기 예측 없이 저온 감시, 스팀트랩 시동 제외, 증류탑 정상 부하 관계 학습.
아래 기본 범위와 함께 [후속 구현·검증](REMAINING_MODULES.md)을 확인하세요.

| ID | 구현 | 간단한 설명 | 한계 |
|---|---|---|---|
| 1 | 탱크 질량수지 | 입출고·알려진 손실 적분과 재고 변화를 비교 | 손실 원인·누설 위치 미확정 |
| 2 | 보일러 질량수지 | 급수·증기·블로다운·총재고로 누설 의심 감시 | 검증된 총재고 입력 필요. 드럼 수위 관측기는 외부 |
| 3 | 열교환기 | 양측 열량·열수지·LMTD·UA로 성능 저하 감시 | 일정 cp의 단상 준정상 대향류 |
| 4 | 필터·배관 차압 | 유량·밀도 보정 후 저항 증가 감시 | 압축성·다상 RTTM 아님 |
| 5 | 기화기 | 예측 대비 저온·출구 온도 한계, 엔탈피 열량 | 정상 예측 모델은 외부에서 제공 |
| 6 | RO 막 | 순구동압·온도 보정 투수성 저하 | 오염물 종류 자동 판별 아님 |
| 7 | 밸브 추종 | 명령–실측 위치 오차를 응답지연 보정 | 스틱션·포지셔너 이상 원인 분리 아님 |
| 8 | 증류탑 수력학 | 증기·액체 부하 보정 차압 증가 | 플러딩 예측 ML 모델 아님 |
| 9 | 스팀트랩 | 공급 중 저온·저음향 및 고온·고음향 패턴 | 현장 보정한 음향·온도 임계값 필요 |
| 10 | 냉동기 열성능 | COP와 두 열교환기의 접근온도 변화 | 냉매 부족·과충전 등 다중고장 분류 아님 |
| 11 | 히트펌프 열성능 | 난방 COP·과냉·토출 과열·회전당 냉매량의 부하별 잔차 | 실제 프로토타입에서 유량 감소 고장 검출 부족. 고장 종류 분류 아님 |

공통 구현: SensorBatch/DiagnosticResult, SI 단위 검사, 품질·운전모드·에피소드,
경과시간 지속 경보, 정상 기준 저장·불러오기, CSV/JSON CLI, 분할 시계열,
설명 포함 목록 API, 기존 세 저장소의 실제 객체 어댑터입니다.

조사했던 세부 연구 중 아직 없는 기능:

- LNG 층별 온도·밀도 성층화 및 롤오버 시점 예측
- 극저온 탱크 단열·진공 이상 원인 분리와 열유입 추정
- 보일러 PCA/EKＦ 기반 관측기 및 음향 누설 위치 추정
- 배관 누설 위치·크기 추정 RTTM/역과도해석
- 밸브 위치 미계측 시 스틱션 추정·원인 분리
- 기화기 착상 두께 추정·해수 편류 공간 진단
- 증류탑 플러딩 선행 예측, 냉동기 고장 종류 분류

기존 process-monitoring-toolkit에서 PCA·CUSUM 등 공통 통계 기능을 연결할 수
있지만, 그것만으로 위 설비별 연구 모델이 구현·검증된 것으로 간주하지 않습니다.
핵심 테스트·합성 데모·외부 객체 연결과 실제 설비 검증은 구분합니다.
