# 설계와 구현 근거

## 구조

`contracts.py`는 단위·시계·품질을 포함하는 입력과 결과를 정의합니다.
`base.py`는 정상 기준, 적용범위와 경보 지속조건을 담당합니다.
`diagnostics.py`는 설비별 독립 물리 지표입니다.
`adapters.py`는 기존 저장소의 공개 객체만 연결하고 외부 solver 코드를 복제하지 않습니다.
`io.py`와 `cli.py`는 선택적 CSV·JSON 경로입니다.
`additional.py`는 증류탑·스팀트랩·냉동기 스크리닝, `streaming.py`는 필요한 과거의
경계 표본을 보존하는 분할 처리, `catalog.py`는 설명 포함 구현 목록입니다.

공통 계약은 time_s[n], values[n,d], channels[d], units[d], valid[n,d],
episodes[n], modes[n]입니다. 출처, 설비 식별자, 시계 식별자도 필수입니다.
`process-monitoring-toolkit`에는 explicit clock_id 필드가 없으므로 입력 어댑터에서
반드시 지정합니다. 출력 시 metadata에 clock_id와 asset_id를 보존합니다.

## 식

물질수지의 양의 손실률은 다음과 같습니다.

```text
unaccounted_loss = ( integral(inflow - outflow - known_loss) dt - Δinventory ) / window_s
```

유량은 구간별 선형으로 보고 사다리꼴 적분합니다. 창 경계가 표본 사이에 있으면
유량의 선형 변화를 적분해 부분 구간을 계산합니다. 재고는 경계 유량의 적분과 관측된
구간 수지 오차를 사용해 보간합니다. 표본 구간 [j,j+1]에서 부분 시간 h, 구간 길이 H,
전체 순유량 적분 F, 부분 적분 Fh이면 M(cut)=Mj+Fh+(h/H)*(Mj+1−Mj−F)입니다.
미지 손실률이 해당 표본 구간 내 일정하다는 가정이며, 선형 유량에 따른 이차 재고 변화도
정확히 처리합니다. 급격한 손실 변화나 비선형 유량에는 센서 간격에 따른 오차가 남습니다.
invalid, mode/episode 변경, max_gap 초과에서는 창을 새로 시작합니다.

단상 대향류 열교환기는 Qh=mh*cph*(Thi−Tho), Qc=mc*cpc*(Tco−Tci),
ΔT1=Thi−Tco, ΔT2=Tho−Tci, LMTD=(ΔT1−ΔT2)/ln(ΔT1/ΔT2)로 계산합니다.
두 접근온도가 같으면 연속 극한값을 사용합니다. UA=(Qh+Qc)/(2*LMTD)입니다.
열량 불일치 비율은 |Qh−Qc|/max(|Qh|,|Qc|)입니다.

차압 보정은 ΔPref=ΔP*(Qref/Q)^n*(ρref/ρ)^r입니다. n, r과 참조 밀도·유량은
사용자가 선언합니다. `density_exponent=r` 기본값은 1입니다. 일정 점도에서 층류는
n=1,r=0, 일정 마찰계수의 관성 극한은 n=2,r=1, 매끈한 관의 Blasius 상관식은
n=1.75,r=0.75입니다. 점도·Reynolds 수 모델이나 영역 자동 선택은 구현하지 않았습니다.
0 차압은 증가 경보를 내지 않습니다. 차압 저하·바이패스·센서 고장은 이 단방향 모델로
검출하지 않습니다. 유량 0은 정규화 불가이므로 UNKNOWN입니다.

RO 정규화 투수성은 Lp_ref=Qpermeate*TCF/(area*NDP)입니다.
TCF·NDP 계산은 공급사 식·검증된 외부 모델에 맡깁니다.
TCF=A_ref/A(T)이며 양의 NDP에서 투과 유량 0은 투수성 0으로 평가합니다.

냉동기 Qe=m*cp*(Tin−Tout), COP=Qe/Pelectric입니다. 등온 증발·응축 가정의
Carnot COP=Tevap/(Tcond−Tevap)도 출력합니다. `enforce_isothermal_carnot_bound=True`는
이 가정이 확인된 경우에만 상한 위반을 UNKNOWN으로 처리하는 선택 옵션입니다.
기본값 False이며, 온도 글라이드·과냉각·축열을 포함하는 사이클의 보편적 상한으로
사용하지 않습니다. 해당 경우에는 별도의 사이클 엔트로피 수지가 필요합니다.

설비별 점수는 기준 성능 대비 감소·증가를 한계값으로 나누거나, 온도·위치의
편차를 해당 단위의 한계값으로 나눕니다. 점수는 확률이 아닙니다.

## 범위와 남은 작업

현재는 정상 기준을 고정하고 배치 또는 bounded replay 방식으로 분할 점수화합니다. 센서 CSV·프로토콜 어댑터,
외부 물성·예측값, 경보 정책을 분리했습니다. 향후 실제 설비별로 해야 할 작업은
센서 위치·주기·단위 매핑, 정상 운전영역과 한계값 결정, 미계측 유량·물성 오차 분석,
독립 고장 사례 평가입니다. 임의의 합성 데이터로 이를 대체하지 않습니다.

새 기능 후보는 유량·온도 의존 UA 모델, 압축성 배관 RTTM 연결, 실제 드럼 재고
관측기, LNG 층별 롤오버 모델, 실측 데이터 기반 밸브·냉동기 고장 분류입니다.

분할 처리의 보존 시간은 물리 창 또는 밸브 지연의 최댓값 + 경보 지속시간 +
2*max_gap_s입니다. 창 경계의 사다리꼴 적분·지연 보간에 필요한 표본 한 개를 추가
보존합니다. 잘못된 청크·설정 변경·이력 표본 한도 초과는 상태를 전진시키지 않습니다.
이 방식은 현재 패키지의 점수화 시점에 상태가 없는 진단기를 대상으로 하며, 임의의
외부 온라인 학습기를 이 래퍼에 넣는 계약은 제공하지 않습니다.
