# 5~6번 추가 개선 — v0.13.0 (2026-11-06)

학습·보정·평가 분할과 원본 행 식별자를 유지했다. 모델 구조는 이전 재사용 평가의
분석을 참고해 설계했으므로 이번 최종 비교도 **재사용 평가**다. 새 독립 고장 성능으로
표현하지 않는다. 새 독립 R290195관측의 물리 지표 확인과 RO36398행 품질 검사는
v0.12의 별도 근거로 유지하고, 이번 학습·보정·모델 선택에 넣지 않았다.

## 5. 히트펌프: 채택한 추가 감시 경로

| 지표 | v0.12 | v0.13 |
|---|---:|---:|
| 전체 고장 정확도 | 97.30% | 97.94% |
| 전체 고장 검출률 | 97.05% | 97.75% |
| 증발기 물 유량 감소(EF) 검출률 | 94.75% | **96.17%** |
| 정상 오경보율 | 0% | 0% |
| 평가 대상 판단률 | 100% | 100% |
| 연속 경보 구간 수 | 41 | 38 |
| 관측 양성 구간 검출 | 35/35 | 35/35 |
| 첫 유효 양성부터 최대 관측 지연 | 520초 | 510초 |

정상490표본의 오경보는0건이며 같은 정상 두 실험의 시간 분할이다. 전체 평가 대상은
5775행이다. TP/FN/FP/TN=5129/156/0/490 → 5166/119/0/490이다.
원시 행 기준 판단률90.16%도 유지했다. 35개는 알려진 실험 조건의 관측 구간이며
독립적인 실제 고장 시작 사건이 아니다. 지연은 시동180초 제외 후 첫 유효 양성부터다.

개선은 약한 EF10.1에서 주로 나왔다. 이 조건의 검출률은26.99→49.08%로 여전히
절반가량 놓친다. 전체 EF96.17%만으로 미세 고장 문제가 해결됐다고 말할 수 없다.

증발온도 감소·전력 증가·압축기 속도 증가·COP 감소의 네 잔차를 부하별로 묶었다.
`ResidualCoherenceDiagnostic`가 정상 학습 평균과 공분산을 계산하고, 이상 방향으로
변한 부분의 Mahalanobis 거리를 구한다. 공분산에는10% 대각 수축과 작은 양의 대각
항을 적용해 강한 상관관계에서도 역행렬이 안정적으로 존재하도록 했다.

별도 정상 보정 자료의99백분위수로 거리를 정규화하고, 기존과 같은 EWMA20초·
CUSUM 감시에 전달한다. 추가 경보를 v0.12 경보와 OR로 결합했다. 공분산·드리프트는
정상 학습, 경보 한계는 별도 정상 보정 자료에서 계산한다. 고장 강도는 평가에만 쓴다.
기존 명목 부하10200/12300W, 시동 제외·중간 제외 구간을 유지했다.

이 경로는 잔차가 함께 변하는 이상을 감지하며 고장 원인을 확정하지 않는다.
미지 부하·다른 설비·다른 운전 모드로의 전이 검증은 없다. 채택은 이번 개발 프로파일의
선택이며 현장 성능 인증이나 자동 보호 적용 승인이 아니다.

## 6. 필터: 새 후보 구현과 기본값 유지

| 재사용 평가 | v0.12 검출률 / 오경보율 | 새 결합 후보 검출률 / 오경보율 |
|---|---:|---:|
| 원래 Test | 68.90% / 2.14% | **70.69% / 2.40%** |
| 기존 시험체 후반 | 100% / 21.58% | **98.30% / 19.57%** |

Test 정확도94.37→94.36%, 후반 정확도94.64→93.86%다. 판단률은 두 자료 모두
100% 유지했다. 새 후보는 검출·오경보의 교환이 남아 **기본 설정으로 채택하지 않았다.**
기본 기준은 `outputs/diagnostic_followup/filter_frozen.json`이다.
새 기준은 `outputs/stage56_ensemble/filter_frozen.json`에 검토용으로 보존했다.

후보 구현은 다음과 같다.

- `FilterBoostedRiskClassifier`: 고정150회 부스팅, 최대 깊이6, 최대 잎15,
  최소 잎30표본, 학습률0.05, L2=1. 내부 무작위 검증 분할과 조기 종료는 사용하지 않음.
- `FilterBoostedLifeModel`: log(남은 교체 수명) 회귀. 짧은 시험이 긴 시험에 묻히지
  않도록 시험별 가중치를 균등하게 주는 대안도 구현.
- `FilterRiskEnsemble`: 기존 ExtraTrees와 부스팅의 산술·기하 결합. 가중치는
  학습 자료 내부 시험 단위 검증에서 선택.
- `HysteresisAlarmDiagnostic`: 확인 후 낮은 해제 한계까지 경보를 유지하는 대안.
  재사용 평가에서 안정적 이득을 보이지 않아 최종 후보도 기존1초 경보를 유지.

히스테리시스는 경보 표시의 유지·해제 정책이며 실제 막힘이 회복됐다는 뜻이 아니다.
부스팅의 잎 값은 부호 있는 예측 기여량이다. NumPy 추론으로 내보낸 뒤 학습 도구
예측과1e-12 이내로 일치하는지 학습 행에서 확인했다. 추론에는 scikit-learn이 필요 없다.
JSON으로 복원하며 pickle은 사용하지 않는다.

## 학습 자료 안에서만 선택한 방법

외부 학습29시험·보정10시험·후반 평가10시험은 그대로다. 원시 시간이 역전된28번
시험은 계속 제외했다. 외부 Test나 보정 자료를 모델 구조 선택에 사용하지 않았다.
다만 개발 아이디어는 이전 재사용 결과에 영향을 받았음을 구분한다.

학습29시험 안에서 GroupKFold3으로 시험 전체를 분리했다. 네 기반 모델을 각각
학습하고, 그 검증 예측으로 여섯 고정 결합을 비교했다. 기준은 FPR5% 이하 영역의
표준화 부분 ROC AUC 평균이다. 무작위 행 분할을 하지 않았으며 같은 시험이 내부
학습·검증에 동시에 들어가지 않는다.

| 학습 내부 후보 | 부분 AUC 평균 |
|---|---:|
| 기존 ExtraTrees | 0.89867 |
| 부스팅 분류 | 0.91052 |
| 시험별 가중 부스팅 분류 | 0.90941 |
| 시험별 가중 수명 회귀 | 0.90420 |
| 선택된 결합: ExtraTrees25% + 부스팅75% | **0.92345** |

선택 후 외부 학습29시험으로 다시 적합하고 외부 보정10시험의 RUL>30초 표본
점수95백분위수를 경보 한계로 정했다. 선택·보정 결과를 고정한 뒤 재사용 평가를
계산했다. 내부 AUC 개선이 최종 자료의 오경보 감소를 보장하지 않은 사례다.
모든 내부 검증 행·점수와30개 ROC 곡선의 수치를 보존했다.

필터의 입력은 차압·유량비와 분진 공급 조건·재료 종류다. 목표는 현재 막힘 시작이
아닌30초 내600Pa 교체 한계 위험이다. 확률 형태 출력도 클래스 가중 학습 결과이므로
교정된 실제 고장 확률이라고 부르지 않는다. 트리·모델 간 예측 차이 역시 신뢰구간이
아니다. 학습 범위 경고를 이유로 평가 행을 빼지 않았다.
