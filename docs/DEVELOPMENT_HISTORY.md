## 0.16의 상세 판단 근거

엔진 외부 분할은 기존 정상 Reference의 학습 10,112 / 보정 4,798 / 정상 평가 4,719행과
AF 4개 평가 23,955행을 유지했다. 다른 고장 종류 파일의 **고장 전 정상** 접두부만
별도 부모 파일로 나눠 학습 5,117 / 보정 8,568행을 추가했다. 추가 자료의 고장 행은
학습에 넣지 않았다. 문맥 선택은 정상 학습 내부 3-fold, 120초 블록·20초 purge로
이루어졌고, 관측 센서 벡터 중복도 확인했다. 이 설계 자체는 이미 본 평가의 실패를
바탕으로 수정되었으므로 최종 평가는 개발 재사용이다.

선택된 기존 필터 기준은 정확도 94.7758%, 검출률 90.0889%, 오경보율 0.0294%,
최대 지연 2314초다. 환경 문맥 후보는 검출률을 99.52%로 올렸지만 오경보율 17.99%로
악화했다. 60초 창 변화 후보는 지연을 102초로 줄였으나 오경보율 0.8382%로 증가했다.
원시 기준을 유지했다. 30/60초 경보 유지는 오경보를 0.4412/0.7721%로 올려 거부했다.

HP는 NF10/NF12 각 정상 시험의 0~40% 학습·50~70% 보정·80~100% 평가와
purge를 유지했다. 부하별 정상 응답 예측에 응축온도를 추가하여 전체 유효 평가
정확도 99.7229%, 검출률 99.6973%, 490 정상 표본 오경보 0을 관측했다. 원자료
6,405행 중 고정 제외 후 대상 5,775행으로 대상 판단률 100%, 원자료 판단률 약90.16%다.
EF10.1은 고장 양성 163개만 있어 별도 오경보율을 산출하지 않았다.

응축온도 응답 제거 시 EF10.1 검출률은 기존 49.08%로 돌아간다. 정상 46.8℃와
EF10.1 46.5℃의 다른 날짜 기록 차이 때문이다. 정상에 합성 ±0.3K 편차를 넣으면
추가 경로 417개 중 414개가 경보했다. 따라서 개선된 원시 검출과 경보 유지 효과는
구분되지만 고장 원인 특이성을 입증한 것은 아니다. 새 독립 고장 수치는 없다.

저장/복원 시 JSON key 정렬이 특징·응답 순서를 바꾸던 문제도 수정했다.
순서를 설정과 동결 기준 모두에 명시하고, 최종 평가를 실제 저장한 JSON에서
복원한 모델로 실행했다. 독립 재집계는 137,262개 **후보 계산 행**을 재구성했다.
이 수는 독립 시험/고장 수가 아니다. 당시 회귀·물리 286개와 객체 연결 7개가 통과했다.

## 보존 원칙

0.17.1은 기본 README를 영어로 바꾸고 한국어판을 별도 보존한 문서 수정 배포다.
RO 원입력 모드와 냉동기 단계별 추가 센서 역할도 README에 드러냈다.
진단 계산 로직과 기존 학습·보정·평가 분할은 변경하지 않았다.

실패 후보와 성공 후보를 함께 남겼다. 과거 수치·정답·분할을 새 버전에 맞춰 몰래
바꾸지 않는다. 원자료와 개인 작업 로그는 공개 소프트웨어에 포함하지 않는다.
당시 소스 해시·자체 코드 스냅샷·선별된 감사 결과는 `evidence/`에서 확인하고,
실측 재현에는 별도로 적법하게 확보한 원자료와 당시 실행환경이 필요하다.
