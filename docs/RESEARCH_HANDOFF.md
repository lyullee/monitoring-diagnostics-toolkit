# 후속 연구 인수인계

## 현재 동결할 결정

엔진 필터는 기존 부하/회전수 기준 유지. 문맥 추가·변화창·경보 유지 후보는 높은
오경보로 거부했다. 히트펌프 response_point는 정상 상태 편차 연구 프로파일이며
증발기 유량 감소 원인 진단으로 승격하지 않는다. HSE 위험 분류의 후반 구간
오경보 문제, 냉동기 추가 단계와 젖은 코일 낮은 검출력도 해결된 것으로 표시하지 않는다.

**다음 개발 전에 읽을 것:** README→MODEL_GUIDE→DEVELOPMENT_HISTORY→
TWO_TARGET_IMPROVEMENT→REPRODUCIBILITY→THIRD_PARTY_NOTICES.
0.16 당시 프로토콜/소스 스냅샷과 현재 배포 소스는 별개다. 공개 시 Git 이력을
새로 시작했으므로 회고 문서가 과거 커밋을 대체하지는 않는다.

## 새 검증 실행 규칙

새 캠페인 ID와 별도 outputs 디렉터리를 먼저 정한다. raw 파일·단위·정답·시각
정의·정상/고장 선별 기준·분할 파일 목록·환경·라이선스를 확보한다. 새 평가 전에
모형/기준/임계값/알람 정책과 수용 기준을 고정하고 해시를 저장한다. 고정 뒤 새
데이터를 평가하고 실패도 보고한다. 고장 정답이 없으면 물리 계산/품질 검사를
수행하되 정확도·검출률을 비워 둔다. 미검출·판단 보류·오경보를 서로 바꾸지 않는다.

보고 표에는 분모와 정상 시간, 원자료·대상 판단률, TP/TN/FP/FN, 사건 검출, 첫 새
경보 지연, 고장 전 활성 경보, 복구 후 경보가 필요하다. 유지 정책의 활성 시간
증가를 원시 감지 개선으로 주장하지 않는다. 한 장치의 시계열 행 수를 독립 고장 수로 세지 않는다.

## 보존 위치와 공개 제외

원 작업 폴더의 `outputs/`는 결과·설정·frozen 기준·행별 예측·시험 XML·실패 후보·
자체 코드 스냅샷을, `research_support/public_data/`는 원자료와 다운로드 메타데이터를
보존한다. 이 두 폴더와 `.upstream/`은 삭제하거나 공개 Git에 추가하지 않는다.
공개 `evidence/artifact_index.json`에는 파일명/크기/해시만 기록하며 유무와 무결성을
비교할 수 있다. 외부 원자료 재배포 권한과 새 사용 목적의 적합성은 별도로 확인한다.
