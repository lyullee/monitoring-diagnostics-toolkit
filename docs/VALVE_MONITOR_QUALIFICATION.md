# 밸브 지속 추종 불량 감시: 실제 자료 기준 통과

v0.8 진단 엔진의 순수 지연·위치 오차 계산은 유지하고, 경보 지속시간을 3초에서 **10초**로 늘린 운영 프로파일을 검증했습니다.
이 프로파일은 사전에 고정한 프로젝트 감시 기준 8개를 모두 통과했습니다.
사용 범위는 **명령–실측 위치의 지속 편차 감시**입니다. 밸브의 모든 고장이나 고장 원인 분류를 검증한 것은 아닙니다.

## 무엇이 새로 검증되었나

- 이전 학습: 2001-10-29. 이전 정상 보정: 11-01. 지연·오차 한계는 그대로 유지했습니다.
- 새 정상 배경 평가: 이전 평가에 사용하지 않은 **17일 × A1/A3 두 밸브 = 34 설비·일**.
- 새 원본은 2,937,600표본이며, 알려진 비대상 고장 1,552표본을 제외했습니다. 판단 표본은 2,935,997개입니다.
- 문서상 인위적 대상 고장이 없는 배경입니다. 정비로 독립 인증한 정상 상태라는 뜻은 아닙니다.
- 고장 확인: 이전 평가 날짜 6일의 f16 공급압력 저하 6건을 그대로 재생했습니다. **새 독립 고장 사건은 0건**입니다.
- 원시 새 날짜 값을 읽기 전에 정책·합격 기준·자료/소스 해시를 `frozen_protocol.json`에 저장했습니다.
- 결과를 본 뒤 임계값·지연·지속시간·합격 기준을 다시 조정하지 않았습니다.

공식 설명서 Table 3/5에 따라 10-30의 A1/A3 f18 구간도 새 정상 배경에서 제외했습니다.
정상/고장 행을 무작위로 섞지 않았고, 한 사건을 잡았다고 전체 고장 구간을 검출로 바꾸지 않았습니다.

## 실제 공장 자료 결과

| 새 정상 배경 약 815.55시간 | 기존 3초 지속 | 개선 10초 지속 |
|---|---:|---:|
| 라벨 기준 정확도 | 99.98566% | 99.99983% |
| 오경보율: 정상 판단 표본 중 경보 비율 | 0.01434% | 0.000170% |
| 오경보 표본 | 421 | 5 |
| 경보 발생 구간 수 | 362 | 2 |
| 유효 정상 관측 24시간당 발생 구간 수 | 10.65 | 0.0589 |
| 대상 중 판단률 | 99.9983% | 99.9983% |

같은 판단 표본에서 비교했습니다. 경보 발생 구간은 유효·대상 표본에서 경보가 연속으로 나온 한 구간입니다.
발생 구간 수가 반드시 독립적인 물리 원인의 수와 같지는 않습니다. 실제 설비의 월간 발생 횟수를 보장하지 않습니다.
새 정상 배경에는 대상 고장이 없으므로 **새 자료 검출률은 산출하지 않습니다**.

| 기존 고장·배경 자료 재생 | 기존 3초 지속 | 개선 10초 지속 |
|---|---:|---:|
| 정확도 | 99.9719% | 99.9832% |
| 고장 표본 검출률 | 91.1555% | 85.1641% |
| 오경보율 | 0.0221% | 0.00676% |
| 고장 사건 검출 | 6/6 | 6/6 |
| 최초 경보 지연 | 7~11초 | 14~18초 |
| 대상 중 판단률 | 99.9983% | 99.9983% |

지속 확인을 7초 늘린 만큼 경보가 늦고 고장 초반 표본을 덜 검출합니다. 짧은 이상은 의도적으로 경보하지 않습니다.
이 상충을 포함해 지속적인 추종 불량을 적은 경보 횟수로 감시하는 용도로 판단했습니다.
기존 고장 자료는 이미 개발에 사용한 사건이므로 **블라인드 고장 검증 결과가 아닙니다**.

## 평가 전에 고정한 합격 기준

| 항목 | 프로젝트 기준 |
|---|---:|
| 새 정상 배경 전체 오경보율 | ≤0.1% |
| 새 정상 배경 판단률 | ≥99.9% |
| 가장 나쁜 설비·일의 오경보율 | ≤0.5% |
| 전체 유효 정상 관측 24시간당 경보 발생 구간 | ≤5 |
| 한 설비·일의 최대 경보 발생 구간 | ≤10 |
| 기존 고장 사건 검출 | 6/6 |
| 기존 고장 표본 검출률 | ≥85% |
| 기존 고장 최초 경보 지연 | ≤30초 |

10초 프로파일은 전부 통과했고 기존 3초 정책은 경보 발생 구간 수의 두 기준을 통과하지 못했습니다.
이는 이번 감시 과제를 위한 자체 기술 기준이며 외부 인증 규격이나 모든 현장의 합격 기준이 아닙니다.
평가 파일 전체·사건별 결과는 HTML/JSON에 공개합니다.

## 실행 가능한 프로파일

`outputs/qualification/configs/A1_persistent_tracking.json`과 `A3_persistent_tracking.json`을 생성했습니다.
해당 DAMADICS 밸브의 학습·보정 설정을 고정한 예제입니다. 다른 밸브에 검증된 파라미터라고 간주하지 않습니다.
입력 CSV는 `time_s,command,position`이며, 시간은 초, 명령·위치는 **0~1**입니다.
원본 DAMADICS의 0~100%를 넣을 때는 두 위치 채널 모두 100으로 나눠야 합니다.
외부 모델이나 새 정상 기준 학습 없이 다음처럼 실행할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe -m equipment_diagnostics run --config outputs/qualification/configs/A1_persistent_tracking.json --data normalized_A1.csv --output tracking_report.json
```

두 프로파일에 대해 CSV→설정 로딩→별도 Python 프로세스 CLI→JSON 결과까지 시험했습니다.
이 연결 시험은 `origin='simulation'`으로 명시했으며 실제 고장 사례 수에 더하지 않았습니다.
진단 엔진 소스는 v0.8과 동일합니다. 기존 비통합 210개·외부 연동 7개 검증과 별개로 신규 실제 자료 집계·프로파일 연결 검증을 수행했습니다.

| 후보 | 확인한 내용 | 이번 검증에 채택하지 않은 이유 |
|---|---|---|
| Zenodo 17154403 양조 열교환기 | 저장소 API 목록과 실제 PDF 확인. CSV 이름은 문서에 있으나 파일 목록에는 PDF 1개만 있음 | 내려받아 추적할 수 있는 원시 시계열 CSV가 없어 학습·보정·평가 분리와 고장 정답을 검증할 수 없음 |
| Zenodo 18755474 시멘트 공장 오염 시험 | 실제 온도·차압 XLSX와 METADATA 확인 | 확인한 온도는 채널 번호로 표시되며 양측 입출구 대응과 질량유량이 없음. 차압만으로 유량을 역산해 검증하지 않음 |
| GRIIDC N7QC01GD 필터 실험 | 공개 메타데이터 확인 | 압력·점도가 전압 단위로 정의되어 Pa·Pa*s 변환 교정과 호환 유량 자료를 확보하지 못함 |
| Mendeley s6d23g2m2w 미세채널 코일 | 데이터 설명의 센서·시험 조건 확인 | 착상·습공기 열질량 전달 실험으로 현재 단상 대향류 UA 모듈의 검증 범위와 다름 |

따라서 이번에 등급을 올릴 수 있는 근거는 밸브 지속 추종 감시의 **지정 실제 자료 범위**입니다.
열교환기 등 나머지 모듈을 현장 고장 진단 검증 완료로 바꾸지 않았습니다.
새 현장·새 고장 종류까지 적용을 인정하려면 그 대상의 검증 자료가 추가되어야 합니다.

## 재현과 감사

```powershell
.\.venv\Scripts\python.exe scripts/qualify_valve_monitor.py
.\.venv\Scripts\python.exe scripts/audit_valve_qualification.py
.\.venv\Scripts\python.exe scripts/render_valve_qualification.py
```

독립 감사는 라이브러리 지표 함수를 쓰지 않고 CSV에서 혼동행렬·경보 구간·고장 사건·지연·합격 기준을 다시 계산합니다.
결과·동결 파일·새 날짜 분리·자료/소스 해시와 원래 기준 모델의 혼동행렬 재현도 확인합니다.
원시 자료와 397만여 행의 예측 CSV는 배포 프로파일 ZIP에 포함하지 않습니다.
