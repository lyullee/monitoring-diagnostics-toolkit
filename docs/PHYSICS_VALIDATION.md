## 발견 사항과 보완

1. **질량수지의 가짜 손실**: 기존 창 경계에서는 재고만 선형 보간해, 선형 유량에
   따른 정상 이차 재고 변화와 맞지 않았습니다. 유량 적분과 관측된 구간 수지를
   함께 보존하는 보간으로 변경했습니다. 선형 유량·구간 내 일정 미지 손실 가정에서
   해석해와 최대 절대오차 약 5.1×10⁻¹⁵ kg/s입니다. 급격한 손실 발생 시각을 표본
   사이에서 복원하는 것은 아닙니다.
2. **유동 영역에 맞지 않는 밀도 보정**: 기존 밀도지수는 항상 1이었습니다.
   `density_exponent`를 추가했습니다. 일정 점도에서 층류 n=1,r=0,
   일정 마찰계수 관성 극한 n=2,r=1, Blasius n=1.75,r=0.75를 검증했습니다.
3. **RO 완전 무유량**: 양의 NDP에서 유량 0을 UNKNOWN 대신 투수성 0으로 평가하도록
   변경했습니다. 계측기 고장·밸브 차단도 같은 신호를 만들 수 있으므로 원인 확정은 아닙니다.
4. **LMTD 수치 안정성**: 접근온도가 비슷하면 log1p, 크기 차가 클 때는 로그 차를
   사용합니다. ε–NTU 9조건의 UA 최대 상대오차는 약 6.3×10⁻¹⁵입니다.
5. **정상 기준 학습 품질**: 학습 시 주지표뿐 아니라 모든 파생 지표의 유한성을 확인합니다.
6. **냉동기 열역학 일관성**: `isothermal_carnot_cop`를 출력하고 명시적인 등온 가정이
   있을 때 `enforce_isothermal_carnot_bound=True`로 초과값을 UNKNOWN 처리합니다.
   온도 글라이드·과냉각·축열이 있는 실제 사이클의 보편적 상한으로 강제하지 않습니다.

비선형 지수 유량에서 샘플 간격을 1→0.5→0.25 s로 줄이면 잔차 최대값은
0.00329280→0.00082323→0.00020581 kg/s로 감소했습니다. 이는 사다리꼴 적분의
2차 수렴성과 일치하며, 임의 비선형 유량에 무오차라고 주장하지 않습니다.

정상 1차 관성 밸브 시험은 30표본 중 28표본을 경보로 표시했습니다. 정상 냉간 시동
스팀트랩은 300표본 중 초기 55표본을 경보로 표시했습니다. 이는 **남아 있는 모델
한계를 확인한 결과**입니다. 스팀트랩은 해당 예제에서 관측 시동 모드를 제외하면
오경보가 없어졌습니다. 이 예제의 60 s 제외 시간을 다른 설비에 일반화하지 않습니다.

## 기준 자료

- [ht 공식 ε–NTU 문서](https://ht.readthedocs.io/en/latest/ht.hx.html#ht.hx.effectiveness_from_NTU): 열교환기 독립 정방향 계산에 실제 사용.
- [fluids 공식 마찰계수 문서](https://fluids.readthedocs.io/fluids.friction.html): 층류 마찰계수와 Blasius 함수를 실제 사용. 관성 극한은 상수 마찰계수로 별도 선언.
- [CoolProp 공식 물성 API 문서](https://coolprop.org/coolprop/HighLevelAPI.html): 포화 상태, 엔탈피·엔트로피 및 기준 상태 설명. 기화기·냉동기 검증에서 실제 사용.
- [WaterTAP 공식 RO 모델 문서](https://watertap.readthedocs.io/en/stable/technical_reference/unit_models/reverse_osmosis_0D.html): 용해–확산 기준식만 참고. WaterTAP 계산 결과를 사용했다고 주장하지 않음.
- [Spirax Sarco 스팀트랩 시험 설명](https://www.spiraxsarco.com/learn-about-steam/steam-traps-and-steam-trapping/testing-and-maintenance-of-steam-traps?sc_lang=en-GB), [TLV 시험 설명](https://www.tlv.com/en-ae/steam-info/steam-theory/trap-considerations/steam-trap-test): 온도·음향 신호의 한계와 장치별 경험 보정 필요성의 근거. 상용 알고리즘을 재현하지 않음.
