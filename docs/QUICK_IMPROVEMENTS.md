## 1. 밸브: 정상 1차 응답

기존 `position(t) − command(t−delay)`에 선택적 정상 모델을 추가했습니다.

```text
tau × dx_expected/dt = command(t−delay) − x_expected
tracking_error = position − x_expected
```

입력 명령은 표본 사이에서 선형 보간합니다. 지연된 명령의 절점이 표본 구간 안에 있으면 구간을 나눠 각각 정확히 적분합니다.
작은 Δt/tau에서는 급수로 상쇄 오차를 줄입니다. 누락·운전 중단·시간 단절·관측 모드/에피소드 변경 때 초기화합니다.
구간 시작 실측 위치로 상태를 한 번 초기화하고 기본 `5*tau` 동안 UNKNOWN으로 둡니다.
이 초기화는 시작 시 이미 있는 고장을 잠시 숨길 수 있으므로 검출률·판단률을 따로 집계합니다.
청크 입력은 전체 이력 재생으로 배치와 일치시키며 기본 10,000표본 한도는 유지합니다.

```python
from equipment_diagnostics import ValveTrackingDiagnostic
model = ValveTrackingDiagnostic(
    {'command': 'command', 'position': 'position'},
    error_limit_fraction=.04, delay_s=1, response_time_s=.5,
    persistence_s=3,
)
```

`response_time_s=0`은 기존 동작입니다. 시간상수는 현장별로 식별해야 합니다. 이번 정상 자료에서 선택된 0.5초를 다른 밸브에 그대로 적용하지 않습니다.
새 옵션은 기존 정상 1차 응답 반례에서 오경보를 없앴고, 독립 ODE 적분과도 일치했습니다.
스틱션·속도 제한·히스테리시스 식별기는 추가하지 않았습니다.

실제 공장 재평가는 기존 DAMADICS A1/A3 자료와 날짜 분리를 유지했습니다.
학습 2001-10-29, 보정 11-01, 평가 11-08/09/17/20/21/22입니다.
기존 학습 자료에서 고른 지연 A1 2초/A3 1초를 유지하고, 시간상수 후보 `[0,.5,1,2,4,8]`를 **학습 자료의 공통 유효 표본 MAE만으로** 비교했습니다.
두 밸브 모두 0.5초가 선택되었습니다. 임계값은 별도 정상 보정 자료의 절대 잔차 99백분위수(최소 0.005), 경보 지속조건 3초입니다.
평가 전에 설정·자료/소스 해시를 동결했습니다. 평가 결과로 다시 조정하지 않았습니다.
정상 학습 MAE는 A1 0.010280→0.010211, A3 0.028027→0.021370입니다. 학습 오차 감소를 실제 고장 성능으로 해석하지 않습니다.

| 실제 공장 평가 | 기존 지연 모델 | 1차 응답 모델 |
|---|---:|---:|
| 정확도 | 99.9719% | 99.9462% |
| 검출률 | 91.1555% | 91.8688% |
| 오경보율 | 0.0221% | 0.0483% |
| 대상 중 판단률 | 99.9983% | 99.9948% |
| TP / FN | 639 / 62 | 644 / 57 |
| FP / TN | 229 / 1,034,747 | 500 / 1,034,440 |
| 고장 사건 검출 | 6/6 | 6/6 |
| 최초 경보 지연 | 7~11초 | 4~11초 |

검출률은 0.71%p 증가했지만 오경보율도 0.0262%p 증가했고 정확도는 0.0257%p 감소했습니다.
오경보 최소화가 목적이면 이번 자료에서는 기존 설정을 유지하는 편이 맞습니다.
표본별 실제 평가 지표·6건의 고장 사건별 검출/지연·공통 표본 비교는 `outputs/quick_improvements/valve_results.json`과 `report.html`에 있습니다.
기존 결과의 TP/FN/FP/TN을 정확히 재현했습니다. 이전에 본 평가 날짜를 재사용한 개발 비교이며 새 블라인드 검증이 아닙니다.
대상은 문서에 기록된 f16 공급압력 저하입니다. 다른 고장 구간을 정상으로 세지 않습니다.
정상 학습 오차가 줄어도 다른 날짜의 오경보가 줄어들 것이라고 보장할 수 없습니다. 기존 모드를 자동 대체하지 않습니다.

## 2. 차압: 점성·관성 혼합 정상 모델

기존 단일 유량지수 모드 외에 다음 양의 두 항을 정상 학습합니다.

```text
ΔP_expected = a × (mu/muref) × (q/qref)
            + b × (rho/rhoref) × (q/qref)^2
a ≥ 0, b ≥ 0
ΔP_normalized = ΔP_measured / ΔP_expected × (a+b)
```

비음수 최소제곱을 두 변수 내부 해와 각 경계 해를 비교해 계산합니다. 절편은 없고 계측 차압의 영점이 맞다는 가정입니다.
독립적인 정상 유량/물성 변화가 부족하면 계수를 식별할 수 없으므로 학습을 거부합니다. 실패한 재학습에서는 이전 기준도 지웁니다.
정상 유량·밀도·점도 범위를 벗어나거나 계산이 비물리/비유한이면 UNKNOWN으로 둡니다.

```python
from equipment_diagnostics import HydraulicResistanceDiagnostic
model = HydraulicResistanceDiagnostic(
    {'pressure_drop': 'dp', 'volume_flow': 'q',
     'density': 'rho', 'viscosity': 'mu'},
    reference_flow_m3_s=.001, reference_density_kg_m3=1000,
    reference_viscosity_pa_s=.001, normalization_mode='mixed',
    growth_limit_fraction=.25,
)
model.fit(train_normal)
result = model.score(evaluation)
```

점도 단위는 **Pa*s**입니다. 밀도/점도 채널을 생략하면 선언한 기준값이 일정하다고 가정하므로 실제 물성 변화 보정이 되지 않습니다.
기존 `normalization_mode='power', flow_exponent=...` 동작은 유지했습니다.
고정 형상·단상 조건에 쓰는 저항 모델이며 밸브 개도 변화·다상·압축성 문제까지 해결한 것은 아닙니다.

독립 `fluids.packed_bed.Ergun`으로 0.5% 이내 계측 잡음을 포함한 정상/저항 증가 데이터를 생성했습니다.
학습/보정/정상 평가/고장 평가 난수 시드를 각각 20261105/06/07/08로 분리했습니다.
양쪽 모델에 같은 25% 공학 한계와 별도 정상 보정 q99 정책을 적용했습니다.

| 시뮬레이션 결과 | 기존 유량지수 2 | 혼합 모델 |
|---|---:|---:|
| 정상 보정 차압의 변동계수 std/mean | 5.58% | 0.29% |
| 정상 평가 오경보율 | 0.17% | 0.00% |
| 저항 40% 증가 검출률 | 100% | 100% |
| 판단률 | 100% | 100% |

독립 정상 운전점과 독립 고장 운전점 각각 600개인 **물리식 기반 시뮬레이션**입니다. 현장 진단 정확도가 100%라는 뜻이 아닙니다.

## 3. 탱크: 계측 오차의 보수적 전파

재고 절대 오차 한계 `eM` kg, 유입/유출/기지손실의 절대 유량 오차 한계 `ei,eo,el` kg/s를 입력할 수 있습니다.
기존 창 평균 질량수지와 보존형 경계 보간에 대해, 양의 적분 가중치와 두 끝점 재고 오차로 다음 최악 오차 한계를 얻습니다.

```text
B = 2*eM/window + ei + eo + el
loss_interval = [measured_loss − B, measured_loss + B]
score = max(measured_loss − B, 0) / loss_limit
```

이는 확률적 95% 신뢰구간이 아니라 **사용자가 선언한 절대 오차 한계**입니다. 센서 사양/교정으로 정해야 하며 데이터에 맞춘 임의 숫자를 권장하지 않습니다.
미계측 흐름·시간 정렬·밀도/재고 추정 오차·창 사이의 급격한 동특성까지 자동으로 포괄하지 않습니다.
창 적분/구간 보간 가정과 입력 유효성이 충족되어야 합니다.

```python
from equipment_diagnostics import MassBalanceDiagnostic
model = MassBalanceDiagnostic(
    {'inventory_mass': 'mass', 'inflow': 'inlet', 'outflow': 'outlet'},
    loss_limit_kg_s=.05, window_s=10,
    inventory_error_bound_kg=1,
    inflow_error_bound_kg_s=.08, outflow_error_bound_kg_s=.05,
)
```

예제의 B는 0.33 kg/s입니다. 실제 적용값이 아니라 시험 설정입니다.
경보에는 측정 잔차가 `loss_limit+B`를 넘어야 합니다. 불리한 계측 오차에서도 경보가 보장되려면 실제 손실이 `loss_limit+2B`를 넘어야 합니다.
모든 오차 한계의 기본값은 0이며 기존 동작과 설정 서명은 유지합니다.
출력에는 원시 잔차·오차 한계·손실 하한/상한을 함께 제공합니다. 하한/상한은 부호를 유지합니다.

| 독립 해석식·오차 시뮬레이션 | 기존 | 오차 한계 반영 |
|---|---:|---:|
| 정상 계측 오차 구간 오경보율 | 41.95% | 0.00% |
| 큰 손실 0.8 kg/s 검출률 | 100% | 100% |
| 작은 손실 0.15 kg/s 검출률 | 69.83% | 6.19% |
| 판단률 | 98.33% | 98.33% |

**오경보 감소와 작은 누설 검출력 감소를 함께 확인했습니다.** 오차 한계가 감시하려는 누설보다 크면, 창을 늘리거나 계측을 개선해야 합니다.
창을 늘리면 재고 끝점 오차 항은 작아지지만 고정 유량 바이어스 합은 사라지지 않으며 검출 지연도 늘어납니다.
보일러 상속 모듈에도 이 선택 기능은 적용되지만, 총재고 관측기 부재는 해결하지 않습니다.
