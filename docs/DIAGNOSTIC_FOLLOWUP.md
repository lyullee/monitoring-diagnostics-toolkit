## 1. 경보 구간·관측 조건 구간·지연 분석

| 재사용 평가 | 연속 경보 구간 전→후 | 음성 구간 내 경보 조각 전→후 | 검출한 양성 관측 구간 | 관측 구간 첫 유효 양성부터 지연 중앙값 / 최대 |
|---|---:|---:|---:|---|
| 히트펌프 | 74→41 | 0→0 | 35/35→35/35 | 30/830초 → **10/520초** |
| 필터 원래 Test | 31→31 | 11→11 | 23/26→23/26 | 2.4/14초 유지 |
| 필터 후반 관측 | 10→10 | 3→3 | 10/10→10/10 | 0/0초 유지 |

연속 경보 구간은 같은 시험에서 경보가 끊기지 않은 구간이다. 음성 구간 내 경보
조각은 뒤에 양성 구간과 이어지는 경보라도 음성 부분을 따로 센 것이다. 따라서
필터 후반의 모든 경보가 나중에 양성과 겹치더라도 조기 위험 경보가 없다는 뜻은 아니다.
필터 음성은 RUL>30초이며 실제로 완전 정상인 필터를 뜻하지 않는다.

35개는 서로 다른 실험 조건의 양성 관측 구간이며 독립적인 실제 고장 시작 사건이
아니다. 알려진 실험 경계와 시동180초 제외 후의 관측에서 계산했다. 지연 역시
실제 고장 시작부터의 시간이 아니다. 관측 시작에 이미 양성이던 구간은 좌측 검열
표시를 남겼다. 사건 단위35/35를 표본 검출률 대신 쓰지 않는다.

필터 Test 전체 유효 관측은 약57.46분, 후반은 약5.34분이다. 이 시간들을 하루·월
단위로 확대해 경보 횟수를 보장하지 않았다. 표본의 시간 폭은 파일 내 대표 샘플
간격으로 계산했고 결측 시간이나 파일 사이 공백을 관측 시간에 포함하지 않았다.

## 2. 히트펌프 미검출 원인과 5번 개선

기존 EF10.1/EF12.1 검출률은 각각 약2.45%, EF12.2는13.50%였다.
많은 미검출 표본은 경보 한계를 넘지만 곧 내려와30초 연속 지속조건을 충족하지
못했다. 약한 고장은 실제 지표 변화도 작아 경보 한계 아래에 머무는 구간이 있었다.
고장 강도는 분석 정답으로만 사용하고 진단 특징으로 넣지 않았다.

`TemporalEvidenceDiagnostic`를 추가했다. 기존 증발기 관련 경로의 정규화 점수만
입력으로 받아 시간상수20초 EWMA를 계산하고, 정상 기준보다 큰 편차를 CUSUM으로
누적한다. 기존 전체 잔차 경로는 그대로 유지하며 두 경로의 경보를 OR로 결합한다.
토출 과열도 등 기존에 정상 드리프트가 컸던 채널을 누적 입력에 다시 섞지 않았다.

- 부하별 드리프트 기준: 기존 정상 **학습** 블록의 EWMA80백분위수.
- 누적 경보 한계: 별도 정상 **보정** 블록에서 관측한 최대 누적값의 바로 위 값,
  최소10점수·초. 점수·초는 통계적 증거의 누적량이며 물리적 에너지가 아니다.
- 정상 부하10200W/12300W 기준을 따로 유지한다. 미지 부하는 판단 불가다.
- 시동180초 제외는 유지한다. 새 경로는 누적 자체가 지속 확인 역할을 하며, 기존
  경로의30초 연속 확인 조건은 유지한다.
- 시간 간격 변화에는 실제 경과시간을 쓰며 결측·긴 공백·실험 경계에서 초기화한다.
  미래 값이나 다음 시험의 측정을 쓰지 않는다.

기존 기초 모델과 추가 모델은 같은 정상 보정 블록을 활용한다. 두 번의 독립된
보정 실험을 확보했다는 뜻은 아니다. 정상 블록의 시간 분리·중간 제외 구간은
v0.11과 동일하며, 원본 정상 학습·보정 지문이 같은지 검사했다.
기존 정상 두 실험의 시간 분리이므로 새 반복시험으로도 해석하지 않는다.

새 검출기는 JSON 저장·복원과 불규칙 시간·결측·스트리밍을 검사했다. 정확한 CUSUM
재생을 위해 스트리밍은 전체 시험 이력을 유지한다. 기본10000행을 넘으면 진행을
거부하므로 실제 시험 경계에서 초기화하거나 이력 용량을 설정해야 한다.

## 3. 필터 조건별 문제와 6번 개선

v0.11 Test에서 A2 미세 분진 검출률은36.92%, A3 중간 분진은93.15%, A4는80.45%다.
오경보649표본은 모두 A3에서 발생했다. RUL30~40초의 음성 구간 오경보율은21.43%로,
전체2.14%보다 높았다. 후반 자료도 교체 시점에 가까운 음성으로 구성되어 전체
오경보율21.58%가 높게 나타난다. 서로 다른 평가 분포의 수치를 직접 순위 비교하지 않는다.

학습29시험·보정10시험·후반 평가10시험을 유지하고 다음 후보를 비교했다.
시각이 역전된28번 시험은 계속 제외했다. Test RUL은 학습·보정에 사용하지 않았다.

| 필터 재사용 후보 | Test 검출률 / 오경보율 | 후반 검출률 / 오경보율 | 결정 |
|---|---:|---:|---|
| v0.11 기준 | 68.90% / 2.14% | 100% / 21.58% | 유지 |
| 재료별 별도95백분위수 보정 | 69.87% / 2.59% | 98.71% / 21.58% | 채택하지 않음 |
| 분진 부하·기준 유량 차압 지표 추가 | 64.02% / 2.20% | 99.46% / 29.36% | 채택하지 않음 |

두 번째 후보는 분진 공급비×운전 경과시간, 유량비 보정 차압, 공급비당 증가율을
추가했다. 공급비는 원 단위가 소거된 비이며 이를 실제 포집 질량으로 부르지 않았다.
두 후보 모두 안정적인 개선을 보이지 않아 기본 설정을 바꾸지 않았다. 소스·기준·
예측·실패 결과를 각각 `outputs/analysis_driven_improvement/`,
`outputs/analysis_driven_dose/`에 보존했다.

대신 출력에 `tree_vote_std`, `training_support_available`,
`training_support_fraction`을 추가했다. 첫 값은 트리 간 예측 차이이며 보정된 고장
확률이나 신뢰구간이 아니다. 학습 범위는 같은 재료의 학습 특징별 최소·최대에
비교한다. Test16364/34473행(약47.5%), 후반222/3206행(약6.9%)에서 적어도 한
특징이 범위를 벗어났다. 이런 경고는 성능 일반화에 주의가 필요함을 보여주며,
이를 이유로 행을 제외해 정확도를 높이지 않았다. 범위 안이라고 정확도를 보장하지도 않는다.

## 4. RO 품질 재검토와 신규 관측

[배포 설명·원본](https://mhkdr.openei.org/submissions/649)과 공정도를 확인했다.
공급 압력은 공급 펌프 뒤·막 용기 앞, 농축 압력은 막 뒤·배압 밸브 앞에 있다.
두 지점 사이 별도 펌프는 표시되지 않지만 공정도는 축척·고도 도면이 아니다.
설명서는 압력센서를 아날로그 센서로 교정했다고 명시하나, 필요한 오프셋·압력 기준·
고도 보정값을 제공하지 않는다. 열을 바꾸거나 일정 압력을 임의로 더하지 않았다.

이전에 확보하지 않았던 WEC-Sim 파형 실험 원본도 추가로 내려받았다. 이는 시뮬레이션
파형을 입력으로 사용한 **실제 RO 장치 실험**이다. 같은 장치의 새 관측이며 독립적인
다른 설비가 아니다. 읽기 전에 기존의 유한 압력·공급압≥농축압 검사 정책을 저장했다.

|---|---:|---:|---:|

고장 정답도 없어 정확도·검출률·오경보율은 산출하지 않는다. 공급자 교정 정보나

## 새 독립 실측 자료: 계산 일치 확인과 고장 성능을 구분

제공 값 자체도 같은 측정값에서 유도되므로 위 비교는 독립 센서 정확도나 고장

기존 부하별 모델을 새 설비에 그대로 적용하거나 평균 행에 가짜 시간 축을 넣지 않았다.

`outputs/diagnostic_followup/`는 최종 비교·기준·예측·경보 구간·독립 감사 결과다.
기존 v0.11의 소스도 스냅샷으로 보존했다. 회귀시험240개와 외부 저장소 연동7개가

EWMA/CUSUM을 유효5775행에서 별도로 재계산했다.

현재 히트펌프 개선은 재사용 자료에서의 결과다. 최대 관측 지연520초와 미검출이
남으며 장기 현장 적용을 확정하지 않는다. 필터는 신규 시험의 독립 검증과 A2/A3
분포 차이를 설명할 수 있는 추가 계측·모형이 우선이다.
