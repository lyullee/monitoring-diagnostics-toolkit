# 필터 검출률 회복·히트펌프 EF 후속 개선 (v0.11.0)

2026-11-05. 이전 v0.10의 학습·보정·평가 분할을 유지했다. 이전 Test뿐 아니라
지난번 미사용이었던 필터 후반 관측도 이제 **재사용 평가**다. 새 독립 자료의 검증
수치는 없다. 네 개발 설정을 실행했으며, 평가 결과를 본 뒤 구조와 경보 정책을
수정한 개발 과정임을 명시한다. 실제 모델 적합과 임계값 계산에는 학습·보정 자료만
썼지만 최종 수치를 새로운 블라인드 검증으로 주장하지 않는다.

## 필터: 추가 운전조건과 경보 설정

[HSE 원본 v8](https://www.kaggle.com/datasets/prognosticshse/preventive-to-predicitve-maintenance)의
차압·유량에 더해 **분진 공급 조건과 재료 종류**를 사용하는 선택적 위험 분류기를
추가했다. 후자의 두 조건은 실제 배포 자료에 기록된 값이다. 고장 정답이나 시험 ID가
아니다. 절대 분진 공급 단위는 가정하지 않고 학습 시험의 원 값 중앙값으로 나눈 비를
사용한다. 재료는 배포 자료의 A2/A3/A4를 고정 범주 1/2/3으로 변환했다.
미지 재료는 임의로 기존 재료로 채우지 않는다.

**따라서 최종 개선 수치는 이 두 운전조건을 확보할 수 있을 때의 결과다.** 차압·유량만
있는 현장에 동일 성능을 약속할 수 없다. 추가 입력 없는 후보도 아래에 공개했다.
지도 정답은 관측 시각부터 처음 차압 600Pa를 초과한 시각까지 시간이다.
`RUL≤30초`의 미래 교체 위험을 분류하며, 현재 막힘 시작의 독립 정답은 없다.

`FilterRiskClassifier`는 과거 10초/2초 압력 추세와 로그 차압·유량비·운전 경과시간,
추세 변동 및 두 운전조건을 사용한다. 총 10특징이며 미래 관측이나 고장 라벨은
센서 행렬에 넣지 않는다. 128개의 ExtraTrees, 최대 깊이 12, 최소 잎 표본 30,
balanced class weight, 고정 seed 42를 학습한다. fit에만 scikit-learn이 필요하며,
배포 기준은 정수 노드·분기·값을 JSON으로 저장한다. NumPy 추론 결과가 학습 도구의
예측과 1e-12 이내로 일치함을 학습 행에서 검사한다. pickle은 사용하지 않는다.
트리 분기의 float32 입력 정밀도도 유지했다. 출력 vote는 교정된 고장 확률이나 남은
수명 자체가 아니다.

학습 29시험, 보정 10시험, 후반 평가 10시험은 이전과 동일하다. 원시 시간이 역전된
28번 시험은 계속 제외한다. 유량·분진 공급 기준값은 학습 시험에서만 계산한다.
각 시험의 알려진 재료·분진 공급 조건은 기존 CSV에서 해당 시험 내 상수임을 확인했다.
Test의 RUL로 어떤 기준값도 계산하지 않았다. 보정 시험의 음성(RUL>30초) 점수
95백분위수로 한계를 정하고 1초 지속 경보를 적용했다.

같은 분류기의 경보 설정 차이도 공개한다. 다음 모든 값은 **재사용 평가**다.

| 분류기 설정 | 보정 음성 분위수 | 원래 Test 검출률 / 오경보율 | 후반 검출률 / 오경보율 |
|---|---:|---:|---:|
| 차압·유량만, 첫 후보 | 97.5% | 51.05% / 1.03% | 95.81% / 17.31% |
| 운전조건 추가, 엄격 경보 | 97.5% | 60.12% / 1.19% | 98.75% / 14.05% |
| 운전조건 추가, 검출 우선 | 90% | 78.48% / 3.70% | 100.00% / 49.56% |
| 운전조건 추가, 중간 경보 | 95% | 68.90% / 2.14% | 100.00% / 21.58% |

검출 우선 설정은 원래 Test에서 검출률을 더 회복하지만 후반 오경보가 v0.10보다
늘어 기본 적용으로 택하지 않았다. 중간 경보는 두 평가 구간 모두에서 검출률 상승과
오경보 감소를 보였다. 다만 개발 중에 확인한 결과이므로 새로운 자료에서 선택을
검증해야 한다. 보정 음성 분위수는 새 평가 자료의 오경보율 상한을 보장하지 않는다.

## 히트펌프: 기존 감시를 유지한 추가 증발기 감시

[TRI-HP 실험 자료](https://zenodo.org/records/5155136)의 기존 명목 부하
10,200/12,300W와 정상 시간 분리(0~40% 학습, 50~70% 보정, 80~100% 평가),
중간 제외 구간, 시동 180초 제외, 30초 지속조건을 그대로 유지했다. 추가 물측 센서나
고장 코드를 특징으로 넣지 않았다. 압축기 속도는 정상 구동변수가 아니라 감시 출력이다.

첫 후보는 모든 잔차를 부하별로 좁게 보정하고 수치 바닥값도 줄였다. EF 검출률은
84.93%로 올랐지만 정상 오경보율이 49.59%(243/490)로 증가해 채택하지 않았다.
토출 과열도 등 기존 채널의 정상 변화까지 과민하게 감시하는 문제가 있었다.

최종 `calibration_scope="evaporator_groups"`는 기존 전체 잔차 감시를 유지하고,
추가 경로에서 증발온도 감소, 전력 증가, 압축기 속도 증가, 난방 COP 감소의 네 방향만
부하별로 보정한다. 각각의 정상 보정 점수 99백분위수와 그룹 최대 점수 99백분위수를
계산한다. 추가 경로의 잔차 바닥값은 0.05K/로그 0.002인 공학적 수치 설정이며
센서 정확도 사양으로 주장하지 않는다. 두 경로의 최대 점수를 경보 판단에 쓴다.
보정되지 않은 명목 부하에서는 UNKNOWN으로 남기므로 다른 부하로의 자동 외삽을
허용하지 않는다. 정상 두 부하의 변동 폭 차이가 다른 조건의 작은 이상을 가리는
문제를 줄였다. 전체 경보의 오경보 보정은 최종 평가에서 별도로 확인했다.

| 고장 | v0.10 검출률 | 최종 검출률 |
|---|---:|---:|
| EF: 증발기 물 유량 감소 | 55.10% | 78.30% |
| CVL: 압축기 밸브 누설 모사 | 97.59% | 97.59% |
| LL: 액관 제한 | 97.97% | 97.97% |
| OC: 냉매 과충전 | 98.16% | 98.16% |

EF는 +23.20%p이며 약 21.70%는 여전히 놓친다. 정상 평가 490표본의 오경보는
0건이지만 같은 두 정상 실험의 끝부분이어서 장기 현장·새 설비 성능이 아니다.
미세 EF 초반 상태는 정상과 겹칠 수 있어 센서 추가 없이 무조건 구분 가능하다고
가정하지 않는다. 고장 종류 분류나 고장 시작 시각 검증도 이번 범위에 포함하지 않는다.

## 새 데이터 검증과 아직 평가할 수 없는 항목

| 항목 | 이번 상태 | 이유 |
|---|---|---|
| 원래 Test와 기존 후반 자료 | 재사용 평가 | 모두 과거 결과를 확인한 자료. 후반을 새 데이터로 재표시하지 않음 |
| 새 필터 시험의 미래 교체 위험 | 미검증, 지표 null | 호환되는 새로운 30초/600Pa 정답 시험을 확보하지 못함 |
| 필터 현재 막힘 진단 정확도 | 평가 불가 | 독립적인 현재 막힘 시작 정답이 없음 |
| 새 히트펌프 물 유량 감소 고장 | 미검증, 지표 null | 호환되는 새로운 실험 행을 확보하지 못함 |

새 공개 자료도 재검색했다. [2026년 증발기 고장 실험 연구](https://www.sciencedirect.com/science/article/pii/S2666546826001710)는
원시 자료가 요청 시 제공되는 것으로 안내되어 있어 이번에 새 원본 행을 확보하지
못했다. 같은 HSE 필터를 재가공한 배포물은 신규 실험으로 세지 않았다.
[유로 막힘 실험 자료](https://doi.org/10.18710/PQ0UWZ)는 다상 슬러리 배관 막힘으로,
이번 가스 필터의 600Pa 교체 기준 및 필요한 입력과 달라 같은 성능 검증으로 대체하지
않았다. 논문 수치를 프로그램의 검증 수치로 가져오지도 않았다.

## API·재현·검증 산출물

```python
from equipment_diagnostics import FilterRiskClassifier, HeatPumpPerformanceDiagnostic

f = FilterRiskClassifier({"pressure_drop": "dp", "flow_ratio": "flow_ratio",
                          "dust_feed_ratio": "dust_feed_ratio", "dust_class": "dust_class"},
                         persistence_s=1)
f.fit(training_batch, training_remaining_life_s)
f.calibrate(calibration_batch, calibration_remaining_life_s, negative_quantile=.95)
prediction = f.score(evaluation_batch)

hp = HeatPumpPerformanceDiagnostic(hp_channels, reference_mode="load_conditioned",
    feature_set="extended", calibration_scope="evaporator_groups",
    evaporator_directional=True, persistence_s=30)
hp.fit(normal_training).calibrate(normal_calibration, quantile=.99)
```

추가 지도학습 API이며 정상 기준 학습 CLI의 11종 목록은 유지한다.
FilterRiskClassifier의 스트리밍은 시험 경과시간을 유지하기 위해 전체 시험 이력을
보관한다. 기본 최대 10,000행을 넘으면 진행을 거부하므로 실제 시험 경계에서
초기화하거나 이력 용량을 명시적으로 설정해야 한다.

`outputs/filter_heatpump_refinement/`、`outputs/filter_heatpump_refinement_final/`、
`outputs/filter_heatpump_balanced/`에 각각 결과와 해당 소스 코드의 스냅샷을 보존했다.
독립 감사는 원본 정답, 기존 모형의 행별 예측, 분할, 원본·코드 해시를 확인하고
혼동행렬과 앞선 후보 수치를 재집계했다. 회귀시험 233개와 외부 저장소 연동시험
7개가 통과했다. 트리 추론 손계산, 인과성, 스트리밍 일치, 미지 재료·부하,
잘못된 기준, 보정 실패 시 복원도 확인했다.

다음 단계는 새 시험을 확보하고 오경보·미검출 비용과 경보 설정을 고정한 뒤
독립 평가를 하는 것이다. 현재 결과는 해당 자료에서의 개발 비교로 한정한다.
